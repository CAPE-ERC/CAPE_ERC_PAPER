# News-source registry

The two CSV files constitute the publication source registry used to document the newspaper and digital-news universe underlying the textual archive. Together they contain 851 distinct source entries covering all 54 African economies. Each record provides the outlet name, country, language label, and website.

The registry is a source frame, not a balanced monthly panel: individual websites may be unavailable in particular months. Monthly collection is therefore evaluated using source-level retrieval diagnostics, retry rules, article counts, and country-month coverage checks. The forecasting manuscript reports retained article coverage separately from registered-source counts.
