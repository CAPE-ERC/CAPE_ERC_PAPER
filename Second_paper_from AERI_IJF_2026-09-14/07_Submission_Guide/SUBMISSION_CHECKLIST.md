# IJF submission checklist

- [x] Main manuscript has exactly five numbered top-level sections.
- [x] Main manuscript anonymized.
- [x] Separate title page contains authors, affiliations, corresponding author, funding, and no-competing-interest declaration.
- [x] Title and abstract frame the paper around forecast evaluation with constructed targets, not GRE forecast superiority.
- [x] General information-set admissibility condition stated for linearly disaggregated targets.
- [x] Monte Carlo section includes the modest current-state DGP, persistent-state stress DGP, and pure-noise placebo; the stress DGP is explicitly labelled an existence calibration rather than an empirical mechanism estimate.
- [x] GDP annual source documented exactly as supplied: `GDP (PPP)-WEO`.
- [x] No unsupported historical WEO vintage is claimed.
- [x] Final-vintage outcome is distinguished from forecast-origin information.
- [x] Future annual years are excluded from forecast-origin GDP lags and recursive training.
- [x] May baseline and July/November release-timing sensitivity reported.
- [x] Earlier favorable 12-month result retained only as a target-information audit.
- [x] One-month effect described as modest, heterogeneous, and benchmark-dependent.
- [x] Raw RMSFE bootstrap interval including zero reported explicitly.
- [x] Country heterogeneity (33/54 economies improve) reported explicitly.
- [x] Information-staleness and revision mechanism diagnostics include null formal tests.
- [x] Exact-text article-level deduplication sensitivity rerun through corrected forecast design.
- [x] Wide factor benchmark uses 159 retained macro series and six frozen PCA factors.
- [x] Current-US-dollar analysis with incomplete provenance excluded.
- [x] Replication package contains simulation outputs/code and corrected empirical outputs/code.
- [x] No claim of invariance to alternative dictionaries, severity mappings, or emphasis coefficients.
- [x] Six substantive main-text figures included and visually checked.
- [x] JEL classification added to both manuscript and title page: C53; C82; E37; O55.
